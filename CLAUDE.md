# UATXcavators TBM: mechanical design scripts

UATXcavators (UATX) is building a DN600 slurry microTBM (micro tunnel boring machine, ~0.6 m bore) for The Boring Company's Not-a-Boring Competition, March 2027. Sam Indyk is mechanical lead.

**Fusion 360 is the model of record.** This folder holds the supporting scripts: CadQuery models that are exported as STEP and imported into Fusion, hand calculations, a three.js viewer with an assembly animation, and a collision audit of that animation.

**Fusion link** (`fusion/README.md`): the Autodesk Fusion MCP server lets Claude run Fusion API scripts in Sam's open Fusion session (hub "UATXcavators", project "Shamir V1"). The `UATXSync` add-in (`fusion/UATXSync/`) pulls this repo every 120 s and imports changed parts and the design constants into the Fusion design "UATX scripts reference"; it never modifies other designs. Run `python tools/fusion_manifest.py` after any geometry change and commit `out/step/parts/` and `fusion/sync/manifest.json`. Fusion designs come back to the repo through the add-in's Export to repo (`fusion/export/<design>/`).

## Current design: Rev I

Rev I = Rev H after a full review with FEA (Oct 28, 2026). Changes and reasons: `docs/manual-00-overview.md` and the Rev I section of `docs/spindle-mount.md`.

- **Ring 1 (bulkhead):** 110 thick, A572 Gr 42 (Gr 50 plate stops at 4 in), Ø384 × 30 counterbore, Ø318.5 bore, 16 × M12 on Ø354. Slurry pipes Ø76.2 × 6.35 (A1085 HSS) at R245, 12 and 6, welded at both ring faces, run to x = 1,255.
- **Cartridge:** seamless tube 323.9 × 60 (E355, Fy 335), turned to Ø318, 15 land + Ø296 groove; split flange 30 thick, OD 383.8, in the ring 1 counterbore; 4 × Ø12 radial anti-rotation pins; 2 × M8 split screws.
- **Cutterhead to shaft:** B-LOC B400 140 × 190 locking assembly (keyless clamp ring: tightening its screws squeezes the hub onto the shaft).
- **Bearings:** 2 × 23228 spherical roller bearings (x = 70 and 470), 29328N spherical thrust bearing, KM28 + MB28.
- **Drive:** Poclain MS18 motor on a bell adapter (Ø300 rear bore) with a 20 mm motor pilot plate; KTR ROTEX 160 jaw coupling, 64 ShD spider, steel hubs; B-LOC B400 130 × 180 on the Ø130 spindle end; window guards. Pump relief 259 bar (rules: +10 % or +20 bar, whichever is higher).
- **Anti-roll fins:** 4 × 20 × 70 × 990 at 1, 3, 9 and 11 o'clock.
- **Lifting:** 4 bosses Ø60 with M20 for Crosby HR-125M hoist rings, x = 155 and 699 at 12 o'clock ± 18°. Machine 1,205.5 kg (2,658 lb), CG x = 423.
- **Thrust ring Rev B (launch):** A572-50, 76.2 thick (86.2 with the spigot, from 3.5 in plate), Ø609.6 × Ø400; register spigot Ø589.5 × 10 × 9 wide with a 1.5 × 0.5 relief groove, in a Ø590.6 × 12 counterbore in the shield rear end (casing joint placeholders: 24 in × 0.375 casing); U-notches 84 wide to R287 at 12 and 6 for the slurry pipes; 4 × Chief WT 5 × 24 in welded saddles at R260, 2, 4, 8 and 10 o'clock (envelope models).
- **Load cases (`src/loads.py`):** F = 4 p A_bore. LC1 303 kN (thrust model), LC2 613.1 kN (121 bar cap), LC3 800.6 kN (158 bar interlock, structural design case), LC4 901.4 kN (2,580 psi pump relief). M = F·e + M_g, e = 105, M_g = 3.05 kNm; side force F_s = 3T/(πR) = 35.1 kN at the stall torque, added as a vector. Torque: T_d = 20 kNm; stall 11.58 kNm.

Rev H files (`src/build_revH_detail.py`, `asm_revH.py`, `calc_revH.py`, `calc_support.py`, `viewer/data/H.json`) are kept for comparison.

## Conventions

- **Units:** mm, N, MPa, kN, kNm. Steel density is 7.85e-6 kg/mm³.
- **Machine frame:** axis +X runs rearward; x = 0 is the ring 1 front face. Angles are measured around the axis, with 0° = 12 o'clock and 90° = 3 o'clock.
- **Viewer and assembly frame:** +Y is up and the floor is y = 0.
  - Group pose = rotation `th` about world Z plus translation `t`.
  - Named poses: FU = −90 (front up), RU = +90 (rear up), H = 0 (horizontal).
  - All groups share a common pivot at x = 300.
- **Allowables (ASD, allowable stress design):**
  - Bending and axial: 0.6 Fy.
  - Shear: 0.4 Fy.
  - Bearing on machined faces: 0.9 Fy.
  - Fillet welds: 0.3 × 482 = 145 MPa.
  - Yield strengths: Fy 345 for A572-50 / S355 (≤ 4 in); 290 for A572-42 (ring 1, 4.5 in); 335 for the E355 tube (60 wall); 241 for the shell and adapter pipes; 655 for 4140 QT.
- **Load cases:** see Current design above and `docs/manual-01-loads-criteria.md`. Chamber 1 bar on the bulkhead (26.8 kN).
- **Required FoS (Rev I):** hand checks ≥ 1.0 on the ASD allowable; FEA membrane + bending ≥ 1.5 on yield at LC1-LC3, ≥ 1.0 at LC4; FEA peaks ≥ 1.0 on yield (local, LC4 reported); bearings s0 ≥ 2; lifting hardware WLL ≥ load (5:1 inside), welded lifting attachments ≥ 3 on yield.

- Every check prints value, allowable and FoS (factor of safety).

## Docs sync (claude.ai project ↔ this repo)

Chats in the claude.ai project "UATXcavators" edit the project docs `claude/<name>.md`. This repo holds the same docs as `docs/<name>.md`. `docs/.sync.json` records each doc's content hash at the last sync, so `tools/docsync.py` can tell which side changed.

Project memory is shared automatically between those chats and Claude Code sessions attached to the project. Design decisions made in chats appear there; read it before changing the design.

**At the start of a session**, if the Projects tool is available:
1. Run `project_info` and list the docs under `claude/`.
2. For each doc, `project_read` it into a scratch file, then run `python tools/docsync.py compare <name> <scratch file>`. Act on the result:

   | Result | Action |
   |---|---|
   | `pull` or `new-in-project` | Copy the project text into `docs/<name>.md`, then run `python tools/docsync.py mark <name>`. |
   | `push` or `new-in-repo` | `project_write` `docs/<name>.md` to `claude/<name>.md`, then mark it. |
   | `conflict` | Overwrite neither side. Show Sam the diff and ask which version to keep. |
   | `in-sync` | Nothing to do. |

3. Commit any pulled docs as `docs: sync from claude.ai project`.

**After changing a doc in this repo**, `project_write` it to `claude/<name>.md` and mark it in the same session.

Without the Projects tool, say that the docs may be behind the project. The nightly scheduled task "UATXcavators docs sync" reconciles them and opens a pull request.

## Setup

Use 64-bit Python 3.11–3.13. The models were built with CadQuery 2.8.0.

```
python -m venv .venv
.venv\Scripts\activate                # Windows  (source .venv/bin/activate elsewhere)
pip install -r requirements.txt
python -m playwright install chromium # only for tools/shoot_viewer.py
```

If `pip install cadquery` fails on Windows, install CadQuery from conda-forge in a conda environment instead.

If the system Python is newer than 3.13, `uv venv --python 3.13 --seed .venv` downloads a 3.13 interpreter for the venv (`--seed` adds pip).

| 4. FEA | `R1_RCB=192 R1_CB=30 python src/fea_ring1.py LC3 facewelded 245` (LC2, LC3, LC4) · `python src/fea_thrust_ring.py LC3 reg casing` (LC2-LC4 × shield / casing; variant `reg` = notches + register) | `out/fea/*.json`, `*.png`; 5-8 min per ring 1 case, 2-3 min per thrust ring case on 2 cores, ~4 GB RAM |
| 5. Hand checks | `python src/calc_revI.py` | Printed table; `out/calc/calc_revI.json` (174 checks) |

- `adscrews/tube_thread` 14.14, `mbolts/adapter_thread` 13.55, `guardscr/adapter_thread` 0.61: screw threads in tapped holes.

## Code map

- `src/paths.py`: output folders. Importing it also sets UTF-8 stdout, because the scripts print Ø, ×, ° and ≈.
- `src/detail_lib.py`: shape helpers and catalogue-style parts:
  - ISO 4762 socket screws: `shcs` and `axial_screws`.
  - 23228 and 29328 bearings with rollers and cage.
  - Lip seals, KM nut, MB washer, fillets.
- `src/build_opts.py`: helpers from the option studies (`revolve`, `ring`, `holes`, `drive_parts`, `vol`, `export`).
- `src/loads.py`: load cases LC1-LC4, side force, resultant moment `moment_at(case, x)`, torque and relief values.
- `src/build_revI_detail.py`: every Rev I part (same structure as Rev H below). Env `R1_RCB` overrides the counterbore radius.
- `src/asm_revI.py`: Rev I assembly (57 steps): riser blocks, lifting bosses, purge supply in two parts, ROTEX hub through the Ø300 bore, motor with pilot plate, guards, thrust ring Rev B.
- `src/massprops_revI.py`, `src/calc_revI.py`: masses/CGs and all hand checks (rows with equations → JSON).
- `src/fea_lib.py`: CadQuery solid → gmsh tetrahedral mesh → scikit-fem P2 solve; pressure, traction and spring BCs by geometric predicates; AMG-CG solver with rigid-body modes; `linearize()` for membrane + bending along a line.
- `src/fea_ring1.py`: ring 1 + weld + shell half model. Pipe modes `open` (Rev H), `welded` (fused, upper bound), `facewelded` (as built). Env `R1_RCB`, `R1_CB`, `PIPE_OD`, `PIPE_ID`. Solutions cached in `out/fea/cache/` (ignored by git).
- `src/fea_thrust_ring.py`: thrust ring + saddles quarter model, compression-only foundation, Hertz-like seat load (env `SEAT_UNIFORM=1` for the old uniform load). Variants `none`, `hole`, `notch`, `reg` (Rev B: notches + register spigot; contact R295.3-304.8 on both supports).
- `out/fea/studies/`: option-study results quoted in manual chapter 02 and 06.
- `tools/make_manual.py`: writes `docs/manual-*.md`.
- `tools/fusion_manifest.py`: per-part STEP files and `fusion/sync/manifest.json` for the UATXSync add-in.
- `fusion/UATXSync/`: the Fusion add-in. `UATXSync.py` is the loader (copied into Fusion's AddIns folder with a `config.json`); `uatx_sync/core.py` (sync, import, export, toolbar) and `uatx_sync/gitops.py` (fetch and fast-forward only) load from the clone and reload after a pull that changes them. It writes `.fusion-sync/` (log, state) in the clone.
- `src/build_revH_detail.py`: every rev H part.
  - Each part is a tuple `(key, name, workplane, colour, explode_dx, viewer_group, assembly_group)` in the list `P` and the dict `parts`.
  - Design constants sit near their parts, for example `FIN_*`, `A_PURGE` and the thrust ring's `TR_*`, `SD_*`, `EAR_*`.
  - Thrust ring parts are in the viewer groups "Thrust ring" and "Jacking cylinders". `calc_support.py` reads only the shell, module, head and drive groups, so the ring does not enter the machine weight.
  - `--check` runs the interference matrix.
- `src/asm_revH.py`: assembly groups and the step list.
  - Steps are defined with `st(phase, title, text, add, remove, moves, focus, dur)`.
  - `add` and `remove` offsets are in world (viewer) coordinates. `moves` are waypoint lists of poses.
  - Motor mass is overridden to 152 kg (catalogue); the modelled motor is an envelope. The cylinders are overridden to 4 × 52.6 kg the same way.
  - Phase 7 (steps 53–55) adds the thrust ring, cylinders and pins with the machine horizontal on the cradle.
- `src/audit_asm.py`: the collision replay. It must use the same easing and pose interpolation as the viewer (`ease`, `lerp_pose`); change both together.
- `src/calc_revD.py`: annular plate solver. `calc_revH.py` loads it and adds `stepped_plate`, a two-thickness plate model of ring 1.
- `src/calc_support.py`: weight of the cantilevered module, head and drive. Masses and CGs come from the detailed model.
- `src/calc_fins.py`: anti-roll fin sizing, T_resist = Σ Nc·cu × A_eff × R. Only fin height beyond the 10.2 mm overcut counts.
- `viewer/index.html`: the single-page viewer.
  - Tabs are at the top. Page text and check tables live in the JS object `PAGES`; the Compare table is `CMP`; the Rev I FEA tab is static HTML in `<section id="fea">`. Edit them in place.
  - Each revision's meshes are in `viewer/data/<tag>.json` (B–I, S).
  - `viewer/fea/*.png`: FEA panels shown on the FEA tab, copied from `out/fea/docs/` (copy again after rerunning the FEA).
  - three@0.160.0 loads from jsdelivr through an importmap.
- `tools/docsync.py`: three-way hash check behind the docs sync.
- `archive/`: rev B–G scripts, STEP files and old viewer templates. Kept for history only and not maintained; they still contain old absolute paths.

## Gotchas

- Viewer: the render loop draws nothing while the Compare or FEA page covers the 3D view (`view3d`). Without that, browsers that render WebGL in software (headless tests) freeze for about a minute when a 3D tab comes back.
- `cq.Solid.makeSphere` gives a hemisphere by default. Pass `angleDegrees1=-90, angleDegrees2=90` for a full sphere band.
- `build_opts.vol()` returns 0 when a boolean fails, so a 0 can hide a failure. Treat unexpected zeros as suspect.
- In assembly steps, groups that move together need the same pivot, or they drift apart mid-motion.
- Viewer CSS: the global `[hidden]{display:none !important}` rule must stay.
- Motor flange pattern, pilot and body are placeholders until Poclain's certified drawing arrives (8 × M20 on Ø335 assumed).
- FEA on Linux needs `libglu1-mesa` (and `libxrender1`, `libxcursor1`, `libxinerama1`, `libxft2`) for gmsh. Weld roots and the pipe-to-hole gap are crack-like corners: their FE stress grows with mesh refinement, so judge them by the weld line method and by linearized stress, not by the peak.
- `build_opts.vol()` style zeros apply to the interference matrix too: an `ERR` or an unexpected 0 can hide a failed boolean.
