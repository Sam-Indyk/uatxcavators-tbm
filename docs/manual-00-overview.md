## Load paths

- **Thrust** (cylinders push the machine into the face; the face pushes back on the bits): bits → spider arms → gussets → hub ring → journal sleeve (contact) → front 23228 inner ring → spindle collar → backing ring → 29328N thrust bearing → cartridge tube shoulder → tube → tube land → split flange → ring 1 counterbore floor → ring 1 → 14 mm fillet weld → shield shell → shield rear end → thrust ring (at launch) or the last jacking pipe → saddles → cylinders → reaction frame.
- **Torque** (motor drives the head; the soil resists): motor shaft → ROTEX coupling → B-LOC 130 × 180 → spindle → B-LOC 140 × 190 → hub ring → arms → bits. Reaction: motor body → pilot plate → adapter → 12 × M16 + 3 dowels → cartridge tube → 4 anti-rotation pins → split flange → 16 × M12 (friction) + 2 dowels → ring 1 → weld → shell → anti-roll fins and skin friction in the ground.
- **Moment** (thrust off-centre on the face): head → spindle → radial couple on the two 23228s (400 apart) → tube → uneven pressure on the ring 1 seat → ring 1 → shell.

## Glossary

| Term | Meaning |
|---|---|
| Bulkhead (ring 1) | The plate that separates the pressurised slurry chamber at the face from the dry machine interior; it carries the full thrust to the shell |
| Slurry | Water-bentonite mix pumped to the face and back; it carries the cuttings |
| Overcut | Radial gap between the cut bore (R315) and the shield (R304.8) |
| Jam | The cutterhead stops against an obstruction while the cylinders keep pushing |
| Interlock | Control-system limit that stops a function (torque 10 kNm; thrust 158 bar) |
| Relief valve | Hydraulic valve that opens at a set pressure and caps it |
| ASD | Allowable stress design: stresses kept below a fraction of yield (0.6 Fy bending and axial, 0.4 Fy shear, 0.9 Fy bearing) |
| FoS | Factor of safety = capacity / demand. "FoS yield" uses the yield strength as the capacity |
| Fy, Fu | Minimum yield and tensile strength of the material |
| FEA | Finite element analysis: the part is split into small tetrahedra and solved for stress |
| Pm, Pb, peak | Through a section, Pm is the average (membrane) stress, Pb the linearly varying (bending) part, peak the remainder at notches; "linearization" separates them |
| Locking assembly (B-LOC) | Keyless clamp ring: tightening its screws wedges two tapered rings between shaft and hub |
| Spherical roller bearing | Roller bearing with a spherical outer raceway; self-aligning, so the shaft may tilt in it |
| s0 | Bearing static safety factor: static load rating C0 / equivalent static load |
| L10 | Bearing rating life: millions of revolutions reached by 90 % of bearings |
| Fillet weld throat | Weld size 0.707 × leg; weld stress = force per length / throat |
| Hoist ring | Swivel lifting eye bolted into a tapped hole; rated in every pull direction |
| Shore D (64 ShD) | Hardness of the coupling's polyurethane spider |
| Hertz contact | Contact stress between curved surfaces (here a cylinder in a slightly larger seat) |
| Winkler foundation | Support modelled as distributed springs: pressure proportional to deflection |
